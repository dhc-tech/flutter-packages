# Security Policy

## Supported Versions

We actively support and provide security updates for the latest released versions of our packages on [pub.dev](https://pub.dev/publishers/dhc.tech/packages).

| Package | Supported Versions |
| ------- | ------------------ |
| `white_label_kit` | `>= 0.0.6` |
| `dig_cli` | `>= 1.8.0` |
| `apple_sign_in_plugin` | `>= 0.0.1-dev.1` |

## Reporting a Vulnerability

If you discover a security vulnerability within any package in this repository, please report it responsibly:

1. **Do not** create a public GitHub issue.
2. Email us directly or submit a private security advisory through [GitHub Security Advisories](https://github.com/dhc-tech/flutter-packages/security/advisories/new).
3. Provide detailed steps to reproduce the vulnerability and impact.

We will review the issue promptly and publish a fix in the next package release.
