# Skill: dig_cli Developer CLI

## Overview
`dig_cli` provides developer workflow automation, asset generation, and feature scaffolding for Flutter projects.

## Key Principles
- Standalone Dart CLI executable: `dart pub global activate dig_cli`.
- Asset Generation: Scans `assets/` and produces strongly typed Dart references in `lib/gen/assets.gen.dart`.
- Clean Architecture Scaffolding: Generates Domain, Data, and Presentation layer structures.
