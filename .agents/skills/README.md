# Flutter Agent Skills

Welcome to the `.agents/skills` directory. This directory contains agent skills and guidelines designed for AI assistants and contributors to the `dhc-tech/flutter-packages` monorepo.

## Base Guidance

All packages follow official Flutter and Dart architectural principles:
- Strict typing and fatal-infos linting
- Maximum Pana health scores (160/160)
- Automated unit/widget test suites
- Zero proprietary leaks and robust error handling
